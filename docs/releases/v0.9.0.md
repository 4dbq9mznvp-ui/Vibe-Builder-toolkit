# v0.9.0 - Maintainer readiness release

This release makes `agentsmd` easier to evaluate as open-source Codex infrastructure.

`agentsmd` is still early, but v0.9.0 gives reviewers a clearer path through the project: synchronized agent instructions, reviewable build plans, source-grounded capability cards, and Codex-ready maintainer workflows.

## Highlights

- Adds a documented Codex maintainer workflow for issue triage, planning, Codex handoffs, pull request review, verification, and release notes.
- Adds a sample maintainer workflow walkthrough under `examples/maintainer-workflow/`.
- Adds contributor onboarding, release history, GitHub issue templates, and a `node --test` CI workflow.
- Records a release checklist for the `v0.9.0` tag and the Codex OSS support brief.
- Keeps capability runners limited to first-party Codex handoff packages.

## Safety Notes

Third-party execution remains disabled.

`agentsmd capabilities run <id> --input <path> --yes` writes reviewable handoff files under `.agentsmd/runs/...`; it does not install dependencies or execute third-party tools.

## Verification

```text
node --test
```
