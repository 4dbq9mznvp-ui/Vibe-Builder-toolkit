# Vibe Builder Toolkit

Vibe Builder Toolkit helps AI-native builders turn useful open-source tools into working project routines.

The first tool, `agentsmd`, keeps Codex, Claude Code, Cursor, and MCP instructions in sync from one project profile. The next layer is capability cards: small, source-grounded notes that explain what a tool does, when to use it, what to watch out for, and how to ask Codex to apply it.

This is not a generic AI productivity platform. The goal is narrower: help builders move from "I starred this repo" to "I know how to use this capability in my project."
